Quick tier on the example

nexus-mcp-ci eval --example on the Nexus-MCP source (53 files, 30 questions, no LLM): median tokens to reach the right file 5,339 with Grep and Read and 1,366 with Nexus-MCP. Right file first: 70% and 93%. Verdict: Likely fit.

Run it on your own code

uvx nexus-mcp-ci eval runs the free offline check on the current folder. uvx nexus-mcp-ci eval --agent claude runs the paid A/B with your own Claude Code login, after it shows the cost.
