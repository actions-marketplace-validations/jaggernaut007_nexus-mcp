  • All three conditions answered all 24 runs correctly.
  • Nexus-MCP used fewer tokens than GitNexus on 8 of 8 tasks and cost less on 6; GitNexus cost $0.002 less on one task, and one task was a tie.
  • Grep and Read cost less than both on this C++ code. Nexus-MCP cost less than Grep and Read on 3 of 8 tasks (the two needle tasks and WeakPtr).
  • GitNexus sends about 17.9k tokens of tool schema on each turn (17 tools); Nexus-MCP sends about 2.3k (8 tools).
  • The GitNexus condition gets its MCP server and the CLAUDE.md block that gitnexus analyze writes; its on-demand skills are not given.

How the comparison was kept fair

  • Same agent, model, prompt, budget and timeout in each condition.
  • Read, Grep and Glob in each condition; a tool server is added to them, not in place of them.
  • Each tool gets what its real user always has loaded: its MCP server and its always-loaded instructions.
  • Indexes built before the runs; a warm-up call so that each run starts with a warm prompt cache.
  • Isolated config folder and --strict-mcp-config for each run.
  • Pinned repo commit and tool versions; ground truth checked with grep against the commit.
  • The same mechanical scoring (file recall and required facts) for each condition; every task is published.

The tasks are in benchmarks/tasks/chromium-base.yaml.

Method

  • Live: Claude Code with Claude Sonnet, medium effort, headless. 6 tasks per repo, 3 runs each; each number is the median over tasks of each task's median of 3 runs.
  • Baseline: Grep, Glob and Read only. Nexus-MCP: the same built-in tools plus the Nexus-MCP server and its instructions.
  • Offline: nexus-mcp-ci eval: about 30 questions made from each repo, the right file from the parser, no LLM; tokens are characters divided by 4.
  • One row per repo: the latest run of each tier. The Grep and Read side does not depend on the Nexus-MCP build, so it can come from an earlier run.
  • The same code can vary by about 20% in cost with 3 runs per task (measured 2026-10-28).

Run it on your own code: uvx --python 3.12 nexus-mcp-ci eval (offline, free) or nexus-mcp-ci eval --agent claude (a paid A/B with your own Claude Code login; it shows the cost first). Full method, raw runs.

Data: benchmarks.json (source of truth) and benchmarks.csv.
